# 1Fi Marketplace

A full-stack e-commerce marketplace demo with built-in **EMI (Equated Monthly Installment)** financing — browse products, view details, and check EMI plans for different tenures. Built as a React (Vite) single-page app backed by a lightweight Express API.

## Overview

1Fi Marketplace lets a user shop for products the way a typical Indian fintech "buy now, pay later" app would: a mobile-style bottom-navigation shell with **Home**, **Shop**, **EMI Dues**, **Limit**, and **Profile** sections, a product marketplace with detail pages, and an EMI calculator that returns monthly installment options for a given product/variant.

The project is split into two independent apps:

| Folder                | Description                                                          |
| --------------------- | -------------------------------------------------------------------- |
| [`client/`](./client) | React 19 + Vite frontend (Tailwind CSS, Redux Toolkit, React Router) |
| [`server/`](./server) | Express 5 REST API serving mock product and EMI data                 |

## Features

- 📱 Mobile-first app shell with bottom tab navigation (Home, Shop, EMI Dues, Limit, Profile)
- 🛍️ Product marketplace listing with brand/category browsing ("Top Brands", "Nearby Stores")
- 🔍 Product detail pages with variant/color configurations, pricing, and images
- 💳 EMI plan calculator — computes monthly payment and total payable for multiple tenures (3/6/9/12 months) with different interest rates
- ⚡ Custom React hooks (`useProducts`, `useProductDetail`, `useEmiPlans`) for data fetching with loading/error state
- 🧾 Simple REST API with in-memory mock product data (no database required)

## Tech Stack

**Frontend (`client/`)**

- React 19, React Router 7
- Vite 8
- Tailwind CSS 3
- Redux Toolkit / React-Redux
- Axios (HTTP client is currently implemented with native `fetch`, see `src/utils/apiClient.js`)
- Framer Motion, Lucide React icons, React Toastify

**Backend (`server/`)**

- Node.js (ESM)
- Express 5
- CORS
- Nodemon (dev only)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+ (recommended, for compatibility with Express 5 / Vite 8)
- npm (comes with Node.js)

### 1. Clone the repository

```bash
git clone https://github.com/snehagupta53361/1Fi-marketplace.git
cd 1Fi-marketplace
```

### 2. Set up the backend (server)

```bash
cd server
npm install
npm run dev      # starts with nodemon (auto-restart)
# or
npm start        # plain node
```

By default the server listens on **`http://localhost:4000`**. You can override the port with a `PORT` environment variable.

Console output on start confirms the available routes:

```
Mock Products API running at http://localhost:4000
  GET /products
  GET /products/:productId
  GET /products/:productId/emi-plan
  GET /products/:productId/emi-plan?variantId=...
```

### 3. Set up the frontend (client)

```bash
cd client
npm install
```

Create a `.env` file inside `client/` with the API base URL the app should call:

```env
VITE_API_URL=http://localhost:4000
```

Then start the dev server:

```bash
npm run dev
```

Vite will print a local URL (typically `http://localhost:5173`) — open it in your browser.

### 4. Build for production

```bash
cd client
npm run build     # outputs static files to client/dist
npm run preview   # preview the production build locally
```

## API Reference

Base path: `/api/products`

| Method | Endpoint                                           | Description                                                                                                                                                           |
| ------ | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`  | `/api/products`                                    | List all products (id, brand, name, price, MRP, default images, rating)                                                                                               |
| `GET`  | `/api/products/:productId`                         | Get full details for a single product, including all variant configurations                                                                                           |
| `GET`  | `/api/products/:productId/emi-plans?variantId=...` | Get EMI options (monthly amount, total payable) for a product variant across standard tenures. If `variantId` is omitted, the product's default configuration is used |

All responses follow the shape:

```json
{
  "success": true,
  "data": { ... }
}
```

Errors return `success: false` with an explanatory `message` and an appropriate HTTP status code (e.g. `404` for a missing product or variant).

## Notes / Current Limitations

- Product data is stored in an in-memory array (`server/data/products.js`) — there is no database or persistence layer yet.
- The client's routes for Home, EMI Dues, Limit, and Profile are scaffolded but may contain placeholder content pending full implementation.
- No authentication layer is currently implemented.
